1 Clicking a bot opens its window. Chat is the default tab and Settings holds today's bot page.
2 A scheduled run still runs in its own chat, so this conversation doesn't fill up. Its answer is posted here, and the chip opens the full run.
3 You talk to the bot here. It sees the posted run answers on its next turn, as a project chat sees an @-bot's answer.
4 A bot's row has a badge with the number of new messages. Bots no longer list their chats in the sidebar.
5 A toast appears when a message comes in while you're elsewhere in the app. Open goes to the bot's Chat tab. It hides after a few seconds and stays while hovered. With the window in the background, the system notification is used instead.
